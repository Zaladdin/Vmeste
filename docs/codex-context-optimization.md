# Короткие инструкции Codex для распознавания

28 октября 2026. Пользователь запросил сокращение служебного контекста с проверкой того же билета. Применена документированная настройка [model_instructions_file](https://learn.chatgpt.com/docs/config-file/config-reference) вместо встроенных инструкций для работы с кодом. Дополнительно personality=none. Изменения относятся только к дочернему процессу распознавания. Выбранная gpt-6.1-sol / medium, способ входа ChatGPT, правила извлечения, строгая JSON Schema, запрет инструментов, ограничения/валидация файлов и переход с текста на изображения сохранены. Файл инструкций создаётся из константы приложения с flag=wx, mode=0600 в проверенном временном каталоге. Глобальные настройки пользователя не изменяются.
