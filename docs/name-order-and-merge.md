# Порядок имени и объединение повторов

Запрос: перестановка фамилии и имени в документах не должна создавать нового человека. Существующие повторы требуется объединять с сохранением выбранного основного ID.

## Поведение

Полные имена сопоставляются по одинаковому набору слов с сохранением их количества. Учитываются регистр, Unicode-нормализация, пробелы и разделитель `/` между частями имени в билетах. `Anna Ivanova`, `IVANOVA ANNA` и `IVANOVA/ANNA` сопоставляются с одним существующим участником. Написание и ID существующего участника сохраняются; печатные варианты имени остаются в источниках документов.

Инициалы, сокращения, пропущенные слова, транслитерация и похожие фамилии не угадываются. Если одному имени соответствуют несколько ID, автоматическое добавление останавливается для проверки, вместо выбора случайного ID или создания третьей записи. Ранее подтверждённые имена документов тоже участвуют в сопоставлении, в том числе когда основной участник называется «Я».

Во вкладке **Люди** блок **Возможные повторы участников** предлагает выбрать основной ID и явно подтвердить объединение. Выбирайте ID, уже связанный с нужным аккаунтом комнаты. Объединение в одной транзакции:

- оставляет выбранный ID и его имя;
- заменяет ссылки в событиях и подтверждённых именах документов;
- сохраняет оригиналы файлов, даты, заметки и результаты распознавания;
- не меняет другие поездки, другие аккаунты или облачные комнаты.

Отмена не меняет данные. При отдельной публикации обновлённого плана в комнату удалённые ID теряют свои привязки; аккаунт удалённого дубля автоматически не переносится на другой ID. Для объединения и повторного применения уже сохранённого результата Codex не вызывается.
