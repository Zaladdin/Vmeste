## Автоматическое добавление событий из документов · 28 октября 2026

Реализован путь: сохранить исходный файл в IndexedDB → отправить PDF/изображение через same-origin API на сервер → извлечь бронирования через OpenAI Responses API в строгую JSON-схему → проверить даты и часовые пояса → атомарно добавить события и связи документа. Каждый перелёт/переезд — отдельное событие, проживание — событие с началом и концом. Результат с пропущенным временем или сомнительными данными сохраняется для ручного уточнения; стандартные часы заселения не подставляются. Даты поездки расширяются только после подтверждения.

Повторный файл определяется по SHA-256; события сравниваются по типу, реальному моменту начала и нормализованному названию. Этот способ не гарантирует распознавания одинакового события при существенно разных формулировках в разных документах. Файлы связываются с несколькими событиями. Устаревший ответ, завершившийся после новой попытки или удаления документа/поездки, не добавляет события. После удаления события черновики остаются доступны через «Уточнить», восстановление требует явного действия.

**Внешний блокер:** ключ API присутствует в окружении, но реальный OpenAI вернул HTTP 429 с кодом `credit_balance_exhausted`, типом `insufficient_quota`. Успешное живое OCR/AI-распознавание не подтверждено. Интерфейс теперь показывает понятное сообщение про баланс (наш API возвращает 503 без Retry-After), сохраняет файл и предлагает повторить распознавание. Результаты имитированных успешных ответов не выдаются за результаты живого AI.
