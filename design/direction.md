# Вместе · первый экран

Concept: `concept.png`, 1536 × 1024. Built-in Image Gen. Direction: an airy travel journal, functional day timeline, a forest green accent and Istanbul panorama.

Tokens: background #ffffff, sidebar #fafbf9, text #182321, muted #727b77, border #e5e9e5, accent #284e3f, sage #eef3ed. UI uses system sans (Segoe UI on Windows), heading 32px/1.2, body 14px/1.6, controls 14px/1.2. Thin outline Lucide icons, 18–22px. Corners 6–10px. Sidebar 230px; main max 1300px; timeline/summary split 2:1; gutters 32px. Mobile navigation becomes a compact header, summary moves below timeline.

Primary copy: вместе, Мои поездки, Документы, Несколько дней в Стамбуле, Участники, Добавить событие, План поездки, Места, Всё под рукой, Перелёт, Проживание, Поездка на этом устройстве, Добавить в этот день.

Components: sidebar with trip picker, trip banner, header actions, tab strip, day selector, timeline row, quiet summary list, native dialog form, document list and place list. No marketing sections. Buttons, links and text remain native HTML.

Necessary extensions: create trip, edit/delete event, local participant names, upload/open/delete files, export/import plan, delete trip confirmation, blank states, errors, mobile. These follow the same tokens. Introductory sample is explicitly labelled as an example. No fictional invitation or AI recognition.

Intentional differences from concept: original panorama asset has its own natural composition; local-storage copy is precise and does not claim all documents are already offline; no ticket document is shown before an actual upload; seed participants are illustrative local names, not connected accounts. Sample trip uses May 2027.

Asset prompt: realistic editorial panoramic Istanbul skyline viewed from Bosphorus, historic mosques, soft afternoon sun, small ferries, no text, no overlay. Generated using built-in Image Gen. Asset: public/istanbul.png.
