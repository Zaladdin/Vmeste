# Даты без года и ночные прилёты

28 октября 2026. Продолжение ближайших исправлений из `roadmap.md`.

## Поведение

- Если в новом распознавании явно прочитаны день и месяц, но нет года поездки,
  сохраняется `--MM-DD`. Год покупки или текущий год не подставляется.
- Форма показывает прочитанные день и месяц. Пользователь дополняет дату
  в формате ДД.ММ.ГГГГ и может исправить ошибочно прочитанные цифры.
- Неполный год и невозможные даты не принимаются. Удаление другого события
  из проверки не переносит набранные значения между бронированиями.
- Неполная дата блокирует импорт даже при `reviewed:true`; сообщение просит
  уточнить год вместо предложения расширить период поездки.
- Перелёт/переезд виден в дне отправления и, если календарные даты отличаются,
  в дне прибытия. Карточка прибытия использует местное время назначения,
  сортируется по моменту прибытия, сохраняет ID события и связи документов.
  В рамках одного дня событие показывается один раз. Учтены перелёты через
  линию перемены дат. Проживание сохраняет отдельное отображение продолжения.

Уже сохранённые старые результаты с `date:null` не содержат день и месяц.
Эта доработка не восстанавливает их из оригинала задним числом: дату можно
уточнить вручную. Повторный платный запрос модели автоматически не запускается.
Схема облачной очереди уже допускает строку `--MM-DD`; миграция базы для этой
доработки не требуется.
