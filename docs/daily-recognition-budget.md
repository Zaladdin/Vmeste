# Дневной лимит распознавания

28 октября 2026. Запрос пользователя: ограничить случайный расход, показать примерную стоимость до загрузки. Начальная настройка 10 попыток/UTC-сутки, редактирование 0–100, 0 — пауза. Счётчик общий для локального сервера, а не вкладки/поездки; хранится в `.local/recognition-budget.json`. Прошлые распознавания до включения этой функции не переносятся в новый счётчик.

Ориентир до выбора файла: ≈0,65 кредита за попытку GPT‑6.1 Sol Standard по последнему тестовому билету. [Тарифы](https://learn.chatgpt.com/docs/pricing): 50 кредитов/млн входных и 250/млн выходных токенов. Это не тариф для API и не жёсткий предел кредитов; другие модели/документы и fallback могут стоить дороже.

## Реализованные гарантии

- Каждая попытка модели резервируется на сервере до inference. Прежний вход login status не оплачивается и не расходует попытку. Ошибочный/оборванный запуск не возвращает попытку: токены могли быть потрачены.
- Текст и последующее изображение считаются отдельными попытками. У исчерпанного лимита новый inference не запускается даже прямым запросом к API. Ограничение есть и для альтернативного API-провайдера.
- Счётчик защищён последовательной очередью и эксклюзивным файловым lock для разных процессов; файл обновляется через sync + rename. Изменение лимита не обнуляет used. Сброс только при наступлении новых UTC-суток.
- Повреждённое состояние, невозможная календарная дата, перевод часов назад, недоступный файл/блокировка прекращают распознавание. Остаточная блокировка после аварии требует восстановления по README при остановленных серверах; автоматического опасного сброса нет.
- GET/PATCH /api/recognize/budget — no-store, loopback Host/origin, PATCH требует точный origin, x-vmeste-recognition:1, строгий JSON и ограничение тела 512 байт.
- Интерфейс обновляет статус после попытки, при focus/online/смене дня. При исчерпании файлы сохраняются без AI; повторное распознавание отключено. Сервер повторно проверяет лимит при устаревшем интерфейсе.
