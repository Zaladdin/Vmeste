# PDF: текст с переходом к изображениям

28 октября 2026. Задача: извлекать текст электронных билетов до вызова Codex, сохраняя прежний путь изображений для сканов и неоднозначных результатов. Модель gpt-6.1-sol / medium сохранена; вход через существующий аккаунт ChatGPT.

По два события, needsReview=false, предупреждений нет. Формулировки заголовков/описаний немного отличаются. Для произвольных документов сохранение качества не доказано.

## Поведение

- Текст извлекается локально, без PNG и без отдельного AI/OCR запроса. Все страницы проверяются, текст ограничен 40 000 символами.
- Изображения на любой странице, сканы, пустой/нечитаемый текст ведут к пути изображений. Консервативно даже логотип может вызвать этот путь.
- Неполный, пустой или требующий уточнения результат текста проверяется повторно через изображения. Применяется только конечный результат; первая попытка не создаёт событий.
- Две попытки имеют отдельные каталоги, общий предел времени 210 секунд. Суммируются фактические usage обеих попыток; если один счётчик отсутствует, неполная сумма не показывается.
- Сохранены лимиты, отмена, запрет инструментов, разграничение инструкций и недоверенного текста, проверка частично повреждённых PDF. Ошибки аккаунта/процесса не маскируются повторным вызовом.
