# Тестовый билет

`test-hotel.png` — синтетическая подтверждённая бронь Bosphorus Garden Hotel в Стамбуле. Заселение: 12 мая 2027, 15:00; выселение: 15 мая 2027, 12:00. Часовой пояс Europe/Istanbul. Используйте поездку, включающую эти даты. Это тестовый документ без персональных данных.

`test-ticket.pdf` — синтетический пример для проверки распознавания. Это не реальный билет или бронирование; персональных данных нет.

В примере два сегмента 11 мая 2027 года:

| Сегмент | Вылет | Прилёт |
|---|---|---|
| Баку GYD → Стамбул IST | 09:30 Asia/Baku | 11:40 Europe/Istanbul |
| Стамбул IST → Париж CDG | 14:00 Europe/Istanbul | 16:30 Europe/Paris |

Создайте поездку с датами, включающими 11 мая 2027, или используйте пример Стамбула. Откройте «Документы» и загрузите PDF с включённым автоматическим добавлением событий. Живое распознавание расходует лимиты/кредиты текущего входа Codex CLI. Повторная загрузка тех же байтов не должна вызывать новый запрос.
